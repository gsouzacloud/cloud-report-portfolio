# Roadmap — AnanimCloudReport

[English](#english) · [Português](#português)

## English

Ideas for future versions — no committed dates, and **not** presented as delivered features.

1. Connectors for additional cloud providers (AWS, Azure, GCP, OCI) behind the same model.
2. Budgets per project and deviation alerts with explainable criteria.
3. Rightsizing recommendations from historical baselines, with approval and result tracking.
4. Wider showback / chargeback with auditable allocation rules.
5. Self-service tenant onboarding and transactional persistence for SaaS scale.

## Português

Ideias para futuras versões — sem prazo comprometido e **não** apresentadas como funcionalidades entregues.

1. Conectores para outros provedores cloud (AWS, Azure, GCP, OCI) no mesmo modelo.
2. Orçamento por projeto e alertas de desvio com critérios explicáveis.
3. Recomendações de rightsizing a partir de histórico, com aprovação e acompanhamento do resultado.
4. Showback / chargeback ampliado com regras de alocação auditáveis.
5. Onboarding self-service de clientes e persistência transacional para escala SaaS.
